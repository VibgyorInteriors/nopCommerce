# Vibgyor Theme

This is a custom theme for Vibgyor Colour & Decor Specialists built on top of nopCommerce.

## Features

- Custom logo support
- Enhanced UI with modern styling
- Smooth animations and transitions
- Responsive design
- Non-invasive - doesn't modify core nopCommerce files

## Installation

1. This theme is already in the `Themes` folder
2. Go to Admin Panel → Configuration → Settings → General Settings
3. Select "VibgyorTheme" as the default store theme
4. Save changes

## Adding Your Logo

1. Place your logo image in: `Themes/VibgyorTheme/Content/images/logo.png`
2. The logo will automatically appear on the site
3. Recommended logo size: 300-400px width

## Customization

All custom styles are in: `Themes/VibgyorTheme/Content/css/vibgyor-custom.css`

You can modify this file to further customize the appearance without affecting core files.

## Updates

This theme is designed to survive nopCommerce updates. Since it doesn't modify core files, you can safely update nopCommerce without losing your customizations.
